# Mission INIT — Auditer la documentation d'un projet HashCode

## Objectif
Identifier les lacunes d'une documentation existante et proposer des corrections prioritaires.

## Livrable
Un rapport court contenant :

- documentation examinée ;
- points clairs ;
- informations manquantes ;
- contradictions éventuelles ;
- liens cassés ou obsolètes ;
- recommandations classées par impact ;
- proposition de structure améliorée.

## Effort estimé
2 à 4 heures.

## Critères d'acceptation
- Les constats citent précisément les fichiers ou sections concernés.
- Les recommandations sont actionnables.
- Les problèmes critiques sont distingués des améliorations de confort.
- Aucun contenu confidentiel n'est copié dans le rapport.
