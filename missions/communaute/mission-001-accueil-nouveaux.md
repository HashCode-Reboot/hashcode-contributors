# Mission INIT — Améliorer l'accueil des nouveaux membres

## Objectif
Créer un parcours simple permettant à un nouveau membre de comprendre rapidement où commencer dans HashCode.

## Livrable
Une proposition de parcours d'accueil documentée avec :

- message de bienvenue ;
- ressources essentielles ;
- première action recommandée ;
- lien vers les missions ;
- méthode pour demander de l'aide.

## Effort estimé
2 à 4 heures.

## Critères d'acceptation
- Le parcours peut être compris en moins de 5 minutes.
- Les étapes sont concrètes.
- Les liens et ressources sont vérifiables.
- La première contribution proposée est réalisable par un nouveau membre.

## Contribution
Créer une issue ou une Pull Request contenant la proposition.
