# Catalogue des missions

Les missions sont le mécanisme principal de contribution.

## Structure d'une mission

Chaque mission devrait préciser :

- **Objectif** : le résultat recherché.
- **Contexte** : pourquoi la mission existe.
- **Livrable** : ce qui doit être produit.
- **Niveau** : découverte, intermédiaire ou avancé.
- **Effort estimé** : ordre de grandeur du temps nécessaire.
- **Critères d'acceptation** : comment vérifier le résultat.
- **Dépendances** : ce qui doit être disponible avant de commencer.

## Niveaux

### INIT
Mission courte, cadrée, destinée à découvrir le fonctionnement.

### CORE
Mission nécessitant davantage d'autonomie et de collaboration.

### PRO
Mission à responsabilité élevée, avec impact sur un projet ou un domaine.
