# Contributeurs

Ce fichier recense les personnes ayant réalisé des contributions reconnues dans le cadre de HashCode Contributors.

## Comment ajouter une personne

Une personne est ajoutée après une contribution effectivement réalisée et vérifiable. Le registre peut indiquer le domaine de contribution et les références utiles.
