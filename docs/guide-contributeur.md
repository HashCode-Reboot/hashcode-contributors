# Guide contributeur

## Étape 1 — Découvrir

Comprendre HashCode, ses projets, ses domaines et les missions actuellement ouvertes.

## Étape 2 — Choisir

Choisir une mission dont le périmètre est compatible avec ses compétences et sa disponibilité.

## Étape 3 — Se signaler

Pour une mission déjà ouverte, commenter l'issue avec une présentation courte et une indication de disponibilité. Pour rejoindre le programme, utiliser le modèle de candidature.

## Étape 4 — Contribuer

Produire le livrable demandé. En cas de blocage, documenter le problème plutôt que disparaître du processus.

## Étape 5 — Faire relire

Ouvrir une Pull Request lorsque le livrable le justifie. Pour les contributions non techniques, fournir les fichiers, liens, captures ou résultats permettant une vérification.

## Étape 6 — Recevoir du feedback

Le feedback peut conduire à une validation, une demande de révision ou une clôture de la mission.

## Étape 7 — Continuer

Une personne qui contribue régulièrement peut prendre davantage de responsabilités selon le parcours défini dans `parcours-contributeur.md`.

## Bonne pratique

Commence petit. Une mission terminée et bien documentée vaut mieux qu'un engagement vague sur plusieurs sujets.
