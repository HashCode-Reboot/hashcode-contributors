## Repositories

Les 15 repositories disposent maintenant d'une roadmap V0.1 et d'une issue de gate Release V0.1.

Les issues d'architecture ont été ajoutées aux projets afin de transformer les fondations et MVP existants en flux d'exécution plus précis.

## Règle d'exécution

Pour chaque projet :
`FOUNDATION → ARCHITECTURE → MVP → REVIEW → VALIDATION → PILOT → MEASURE → RELEASE`

Chaque issue doit expliciter les casquettes mobilisées, les livrables, les critères d'acceptation et la preuve attendue.

## Limitation d'automatisation

La connexion GitHub actuellement disponible permet les écritures de fichiers et d'issues, mais n'expose pas ici les opérations d'administration nécessaires pour créer les labels, milestones et GitHub Projects. Ces éléments restent donc à appliquer lorsque les opérations correspondantes sont disponibles.
