## Lecture

Chaque projet doit avoir au minimum :
1. un référent produit ;
2. un expert du domaine quand le problème est métier ;
3. un responsable technique ;
4. une capacité QA ;
5. une capacité sécurité adaptée au risque ;
6. une capacité de mesure d'impact avant pilote.

Une personne peut porter plusieurs casquettes dans une petite équipe. Le tableau décrit les compétences nécessaires, pas nécessairement 15 personnes distinctes.
