# Contribuer à HashCode

Merci de vouloir contribuer à HashCode.

## 1. Avant de commencer

Lis le README, le guide contributeur et la mission que tu souhaites réaliser. Si une information manque, demande une clarification dans l'issue concernée plutôt que de partir sur une hypothèse importante.

## 2. Choisir une mission

Privilégie une mission dont l'objectif, le livrable et les critères d'acceptation sont suffisamment clairs. Une mission peut être technique ou non technique.

## 3. Travailler proprement

- Fais des changements ciblés.
- Documente les décisions importantes.
- N'ajoute jamais de secret, mot de passe, clé API ou donnée privée.
- Respecte les conventions du dépôt dans lequel tu travailles.
- Signale rapidement un blocage.

## 4. Pull Request

Une Pull Request doit expliquer :

- ce qui a été fait ;
- pourquoi ;
- comment vérifier le résultat ;
- les limites ou travaux restant à faire.

## 5. Revue

Les contributions peuvent être demandées en révision. Le feedback porte sur le travail et les critères de la mission, pas sur la personne.

## 6. Contribution non technique

Les mêmes principes s'appliquent aux contenus, à la communauté, au design, à la communication et à la documentation. Une contribution utile n'a pas besoin d'être du code.

## 7. Transparence

Le statut de Contributor est basé sur des contributions observables. Il n'est pas garanti par une candidature et ne dépend pas d'une promesse de rémunération future.

## 8. Code de conduite

Toute participation doit respecter le [Code de conduite](CODE_OF_CONDUCT.md).
