# Sécurité

## Signaler une vulnérabilité

Les vulnérabilités de sécurité ne doivent pas être publiées dans une issue publique avant qu'un responsable ait pu les examiner.

Lorsque cela est possible, utilisez un canal privé de contact avec l'équipe HashCode et fournissez :

- une description du problème ;
- les étapes permettant de le reproduire ;
- l'impact observé ;
- les versions ou environnements concernés ;
- une proposition de correction si disponible.

## Règles pour les contributeurs

Ne publiez jamais de secret, identifiant, jeton, donnée personnelle ou information confidentielle dans ce dépôt ou dans une Pull Request.

Pour les missions de cybersécurité, utilisez exclusivement des environnements autorisés et des cibles explicitement définies par la mission.
