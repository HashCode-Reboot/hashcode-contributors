# HashCode Contributors

> Construire HashCode, ensemble.

**HashCode Contributors** est le point d'entrée officiel pour rejoindre, comprendre et faire grandir l'écosystème HashCode par la contribution concrète.

## Pourquoi ce dépôt existe

HashCode ne cherche pas seulement des membres. Nous construisons un réseau de personnes capables de transformer des idées en contributions utiles : communauté, contenu, design, développement, cybersécurité, intelligence artificielle, documentation et projets.

Le principe est simple : **intérêt → mission → contribution → confiance → responsabilité**.

## Parcours Contributor

```text
Candidat
   ↓
Première mission
   ↓
Contributor
   ↓
Contributor actif
   ↓
Core Contributor
   ↓
Lead
```

Les niveaux décrivent des responsabilités et des contributions observables. Ils ne constituent pas un classement des personnes.

## Domaines de contribution

- Communauté
- Communication
- Contenu
- Design
- Développement
- Cybersécurité
- Intelligence artificielle
- Documentation
- Projets

## Comment commencer

1. Lire `CONTRIBUTING.md`.
2. Comprendre le fonctionnement dans `docs/guide-contributeur.md`.
3. Explorer les missions dans `missions/`.
4. Choisir une mission adaptée à son niveau et à son temps disponible.
5. Réaliser le livrable et documenter le travail.
6. Soumettre une Pull Request lorsque nécessaire.
7. Recevoir du feedback et poursuivre son parcours.

## Règle fondamentale

Une mission HashCode doit avoir :

- un objectif clair ;
- un contexte compréhensible ;
- un livrable identifiable ;
- des critères d'acceptation ;
- une estimation raisonnable de l'effort ;
- un responsable du suivi lorsque nécessaire.

## Fonctionnement

Le dépôt sert à organiser le programme Contributor. Les projets opérationnels restent dans leurs dépôts respectifs. Une contribution peut donc commencer ici puis être réalisée dans le dépôt HashCode concerné.
